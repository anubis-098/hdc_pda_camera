สรุปโปรเจค PDA Camera
======================

คำอธิบายแบบง่าย
----------------
โปรเจคนี้เป็นแอปกล้องบนเว็บสำหรับพนักงานคลังสินค้า ใช้กับ Zebra TC22
เพื่อถ่ายรูปสินค้าแล้วส่งเข้าโฟลเดอร์ที่กำหนดบน File Server ได้ทันที
ผู้ใช้เพียงเลือกโฟลเดอร์ กดถ่ายภาพ ตรวจสอบรูป แล้วกดยืนยันเพื่อบันทึก

ระบบจะพยายามใช้ภาพนิ่งจากกล้องจริงที่มีความละเอียดสูงก่อน จากนั้นจะตัดภาพ
ตามกรอบที่เห็นบนหน้าจอ และปรับขนาดตามที่เลือกในตั้งค่า เช่น 1080x1920,
720x1280 หรือภาพจัตุรัส 1080x1080 ภาพที่ตรวจสอบก่อนยืนยันและไฟล์ที่บันทึก
เป็นภาพเดียวกัน หากกล้องไม่รองรับภาพนิ่งหรือภาพนิ่งมีสัดส่วนต่างจากภาพสด
ระบบจะใช้ภาพจากหน้าจอกล้องเป็นวิธีสำรองโดยอัตโนมัติ

เลือกคุณภาพได้ 3 ระดับ: คมชัดสูง, สมดุล และไฟล์เล็ก ขนาดไฟล์ขึ้นอยู่กับ
รายละเอียดภาพ แอปจะจำขนาดภาพ อัตราส่วน คุณภาพ ภาษา และโฟลเดอร์ที่เลือกไว้
หน้า Confirm แสดงเฉพาะขนาดภาพและโฟลเดอร์ปลายทางเพื่อให้อ่านง่าย

PDA Camera คือเว็บแอปสำหรับใช้งานบนเครื่องสแกน Zebra TC22 หรือโทรศัพท์ Android
เพื่อถ่ายภาพหน้างาน แล้วส่งภาพไปเก็บไว้ใน File Server ผ่านเครือข่ายภายในบริษัท
เหมาะสำหรับงานคลังสินค้า เช่น ถ่ายภาพสินค้าขาเข้า สินค้าส่งออก หรือกรณีอื่น ๆ

การทำงานโดยสรุป
----------------
1. เปิดเว็บแอปผ่าน Google Chrome
2. เลือกโฟลเดอร์ปลายทางก่อนถ่ายภาพ ได้แก่ Inbound, Return, Outbound หรือ Other
3. แสดงภาพจากกล้องแบบเต็มหน้าจอ คล้ายแอปกล้องมือถือ
4. กดปุ่มถ่ายภาพ ระบบจะหยุดภาพและแสดง Preview
5. เลือก Confirm เพื่อยืนยัน หรือ Cancel เพื่อถ่ายใหม่
6. ระบบจะลดขนาดและบีบอัดภาพด้วย Canvas ในหน่วยความจำของเบราว์เซอร์
7. ส่งภาพไปยังเซิร์ฟเวอร์ และบันทึกเป็นไฟล์ JPEG ในโฟลเดอร์ที่เลือก

ความสามารถหลัก
---------------
- ถ่ายภาพและ Preview ก่อนบันทึกจริง
- บีบอัดภาพก่อนส่ง ช่วยลดขนาดไฟล์และลดภาระเครือข่าย
- รองรับอัตราส่วนภาพ เช่น 9:16, 3:4, 4:3 และ 1:1
- ปรับ Resolution ของภาพได้
- ซูมด้วยปุ่ม Slider การลากนิ้ว และการใช้นิ้วกางเพื่อซูม
- สลับกล้องหน้าและกล้องหลังได้ หากอุปกรณ์รองรับ
- แสดงข้อมูลกล้องและความสามารถของอุปกรณ์ผ่านปุ่ม Info
- รองรับภาษาอังกฤษและภาษาไทย
- เปิดดูภาพที่บันทึกไว้ และเลือกลบภาพหลายรายการพร้อมกันได้

ส่วนประกอบของระบบ
------------------
- Frontend: HTML, CSS และ JavaScript แบบ Vanilla ไม่ใช้ Framework ขนาดใหญ่
- Backend: Node.js และ Fastify รับไฟล์แบบ Multipart และเขียนลง Storage
- Docker: ใช้สร้างและรันระบบให้ติดตั้งบน Ubuntu Server ได้ง่าย
- Nginx: ใช้เป็น Reverse Proxy และจัดการ HTTPS ในเครือข่ายภายใน

ตำแหน่งจัดเก็บภาพ
------------------
ระบบสามารถบันทึกภาพลงโฟลเดอร์ Local หรือ File Server ที่กำหนดผ่านไฟล์ .env
ตัวอย่างโฟลเดอร์ปลายทาง:

  Inbound
  Return
  Outbound
  Other

ภาพอยู่ในโฟลเดอร์ที่เลือกโดยตรง ชื่อไฟล์มีวันเวลาและรหัสเฉพาะเพื่อไม่ให้ซ้ำกัน

การใช้งานในเครือข่าย
---------------------
สำหรับการเปิดกล้องผ่าน Chrome ควรเปิดเว็บด้วย HTTPS เช่นผ่าน Nginx และ mkcert
แล้วติดตั้ง Root CA ให้กับเครื่องคอมพิวเตอร์และ Zebra TC22 ที่ใช้งาน
การใช้ HTTP หรือ Chrome Flag เหมาะสำหรับการทดสอบชั่วคราวเท่านั้น

การรันแบบ Node.js
------------------
1. ติดตั้ง Node.js
2. สร้างไฟล์ .env จาก .env.example และกำหนดตำแหน่ง Storage
3. ติดตั้งแพ็กเกจด้วยคำสั่ง: npm install
4. เริ่มระบบด้วยคำสั่ง: npm start
5. เปิดเว็บที่: http://SERVER_IP:8090

การรันแบบ Docker
-----------------
1. เตรียมไฟล์ .env และกำหนด STORAGE_HOST_PATH ให้ชี้ไปยังโฟลเดอร์จัดเก็บภาพ
2. หากใช้ SMB File Server ควร Mount Share บน Ubuntu ก่อน
3. เริ่มระบบด้วยคำสั่ง: docker compose up --build -d
4. ใช้ Nginx รับ HTTPS และส่งต่อมายังแอปที่พอร์ตภายใน 8090

ข้อควรระวัง
-----------
- ผู้ใช้ที่รัน Node.js หรือ Container ต้องมีสิทธิ์เขียนลงโฟลเดอร์ปลายทาง
- Zebra และ Server ต้องอยู่ในเครือข่าย Wi-Fi เดียวกันหรือเข้าถึงกันได้
- ต้องตั้งค่า HTTPS และติดตั้งใบรับรองที่เชื่อถือได้ เพื่อให้ Chrome อนุญาตกล้อง
- ไม่ควรเก็บรหัสผ่าน File Server ไว้ใน GitHub ควรเก็บไว้ในไฟล์ .env เท่านั้น
